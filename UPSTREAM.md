# Upstream provenance

This source release is based on
[InternRobotics/InternNav](https://github.com/InternRobotics/InternNav). The
working research branch was exported from commit
`d2a1f5cda7be6e91defefbd58365f181ede16abe` of
`Zimoc02/InternNav_re`, branch `feature/pixel-goal-latent-refeed`.

The public repository starts with a clean Git history so that development logs,
captured sensor data, local commands, and machine-specific material from the
research workspace are not published. This does not remove the upstream
copyright: the Intern Robotics MIT notice is retained in `LICENSE`, and the
upstream project is acknowledged in the main README and citation metadata.
